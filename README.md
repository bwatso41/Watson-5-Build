Portions of the written content for this website were generated with the assistance of ChatGPT and were reviewed and edited by the student. All HTML and CSS were written by the student.

The Indie Film Collective is multi-page webpage meant to tell the community about its services involving filmmaking and aspiring creative videographers. The pages included are Screenings, Workshops, and Collaborations. 
The HTML is semantic and validated. 
The CSS is responsive. 
There is no Javascript.
